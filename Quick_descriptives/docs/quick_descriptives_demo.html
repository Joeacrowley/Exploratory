Quick_descriptives: function reference and usage

What this is

This document demonstrates the functions in the QuickDescriptives package. Unlike the old workflow (functions defined inside Quarto chunks, then writeLines(deparse(...))’d out to loose .R files), the functions here live in ../R/*.R as ordinary package code with roxygen documentation. This .qmd only uses the package – it doesn’t define anything.

While the package is still a pilot (not yet installed), devtools::load_all() loads it straight from source, same as library() would once installed.

ctabs() + ctabs_xlsx()

Crosstabs several outcomes against several predictors at once, exportable to a formatted Excel workbook. ctabs() always returns an overview element too – marginal frequencies (via count_across()) for every variable involved, outcomes and predictors alike – alongside the tables element holding the actual crosstabs. This isn’t optional: ctabs_xlsx() always writes it as the first (“Overview”) sheet in the workbook.

tbl <- df |> ctabs(vars = c("HEdQual3"), preds = c("RClassGp", "RAgeCat"))
